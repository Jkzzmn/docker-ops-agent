# UI/UX 개선 · 2026-10-21

기존 Vue 화면과 실제 SSE 노드 추적, 프로젝트 선택, 사람 확인·승인 기능을 유지하면서 시각적 정보 우선순위를 조정했습니다. 백엔드의 라우팅·진단·권한 정책은 변경하지 않았습니다.

## 변경 내용

- 옅은 중립 배경과 흰 카드로 영역을 구분하고, 강한 색·그림자는 줄였습니다. 강조색은 기존 청록 계열을 유지했습니다.
- 처음부터 긴 명령을 나열하지 않고 상태·설정·네트워크·메모리 점검 및 교육 카드를 짧은 제목으로 표시합니다. 원래 질문/명령은 그대로 전송합니다.
- 답변을 실행 상세보다 먼저 보여주고, 근거 충족·도구 호출·토큰은 별도 요약 영역으로 분리했습니다. 미측정 값을 임의의 100%나 0%로 바꾸지 않습니다.
- 실행 노드는 읽기 쉬운 한국어 이름과 원래 scope.node ID를 함께 표시합니다. 여전히 실제 NodeStarted에서만 생기며 실행하지 않은 단계는 추가하지 않습니다.
- 프로젝트 관리와 모델 연결 정보는 접어서 펼칠 수 있게 정리했습니다. 선택·미리보기·실제 대상 전환의 기존 계약은 유지합니다.
- 입력창을 스크롤하는 피드와 분리해 좁은 화면에서도 계속 접근할 수 있게 했습니다. 모바일 safe area와 가로 넘침을 처리했습니다.
- 한글 조합 확정 Enter 및 Shift/Ctrl/Alt/Meta+Enter가 전송으로 오인되지 않게 했습니다. 일반 Enter만 전송하고 Shift+Enter는 줄바꿈합니다.
- 이전 내용을 읽으면 자동 따라가기를 멈추고, `최신 답변 보기`를 누르거나 아래로 내려가면 다시 따라갑니다.
- 수신 중지 버튼이 서버 작업 취소를 보장하지 않는다는 기존 상태 계약을 입력 영역에도 표시합니다.
